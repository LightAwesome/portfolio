Buffer Neon and Buffer Radon are subsets of Monaspace Neon and Monaspace Radon
(https://github.com/githubnext/monaspace, v1.400), instanced and subset to Latin for the web.
They are renamed because the SIL Open Font License reserves the name "Monaspace" for
unmodified fonts. License: OFL.txt in this folder.
